Reads the Current Cum sheet in each .xlsx. Nothing leaves your browser — parsing happens locally.
Input

One file per project

Each workbook should be a "Cost (Saving/Overrun)" / CVR report with a Current Cum tab listing pay items with cumulative PV, EV and AC.

Method

AC compared to EV, per item

Every pay item is classified by how its Actual Cost relates to its Earned Value — missing cost, cost with no progress, overrun, or in line.

Output

Reviewed on screen, exported to Excel

Browse flagged items here, then download a workbook with Consolidated Data, Flagged Items, Project Summary, Flag Breakdown and category tabs.

How items are classified

Every pay item with any recorded activity falls into one of these buckets, based on comparing Actual Cost (AC) to Earned Value (EV).

Project Summary

Direct-cost totals are computed the same way each source file computes its own Grand Total, so they should tie out exactly.

Expenditure by Category

Flagged by Category
